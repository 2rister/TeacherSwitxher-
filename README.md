# Interesting People — печатный комплект A2

Раздаточные материалы к игре **Jeopardy: Interesting People (A2)**.
Тексты для чтения и упражнения по **Исааку Ньютону, Джону Леннону и принцессе Диане**.
Каждое задание построено на факте, который есть на игровом поле Jeopardy, — так
раздатка и игра проверяют одно и то же.

## Что печатать

Три версии одного и того же комплекта — берите ту, что нужна сейчас.

| Папка | Что это | Когда брать |
|---|---|---|
| `materials/pdf/` | **цветная**, как афиша | основной вариант, «парадная» печать |
| `materials/pdf-bw/` | **ч/б, экономная** | обычная печать на класс: фон убран, плашки заменены на рамки, файлы в 7 раз легче |
| `materials/docx/` | **редактируемая** в Word | когда надо поправить текст или задание под свою группу |

Печатать **без масштабирования** («Actual size» / 100%), A4, поля уже в макете.

| Файл | Стр. | Содержание |
|---|---|---|
| `00-complete-pack.pdf` | 13 | весь комплект одним файлом |
| `01-isaac-newton.pdf` | 3 | текст → упражнения 1–2 + глоссарий → упражнения 3–5 |
| `02-john-lennon.pdf` | 3 | то же |
| `03-princess-diana.pdf` | 3 | то же |
| `04-charles-darwin.pdf` | 3 | то же |
| `05-mixed-round.pdf` | 2 | сводный раунд по трём персонам из игры + Final Jeopardy |
| `06-answer-key.pdf` | 2 | ключи + заметки для учителя |
| `07-grammar-newton.pdf` | 1 | **Past Simple**: тест a/b/c + раскрыть скобки |
| `08-grammar-lennon.pdf` | 1 | то же |
| `09-grammar-diana.pdf` | 1 | то же |
| `10-grammar-mixed.pdf` | 2 | все трое вперемешку: тест, вопросы, скобки, неправильные глаголы |
| `11-grammar-answer-key.pdf` | 2 | ключи к грамматике + заметки |

В `materials/pdf-bw/` те же файлы с суффиксом `-bw`. В `materials/docx/` — те же
листы без суффикса, по одному файлу на лист (сводного файла нет).

**Раздавать ученикам листы I–V и VII–X. Листы VI и XI — только для учителя.**

Итого 23 страницы A4: чтение (I–VI) и грамматика (VII–XI). Блоки независимы — грамматику
можно давать до текстов, после или отдельно.

### ⚠️ Нумерация сдвинулась

С добавлением Дарвина листы после III получили новые номера. Если печатали раньше —
сверьтесь: `IV Дарвин` (новый) · `V` сводный раунд (был IV) · `VI` ключи (был V) ·
`VII–IX` грамматика по персонам (были VI–VIII) · `X` сводная грамматика (был IX) ·
`XI` ключи к грамматике (был X).

**Дарвина нет в вашей игре Jeopardy** — он единственный из персонажей, кого нет на
игровом поле. Поэтому задание 5 на его листе называется не «Back to the board», а
**«New for the board»**: три готовых вопроса, которые можно добавить в игру.

## Структура листа персоны

- **стр. 1** — портрет, даты, текст для чтения с нумерацией абзацев
- **стр. 2** — задание 1 (True / False / Not Given), задание 2 (заполнить пропуски
  со словарной подсказкой) и блок **Words to know** — глоссарий A2
- **стр. 3** — задание 3 (ответить на вопросы), задание 4 (соединить половины),
  задание 5 (Back to the board — вопросы прямо из игры)

У Дианы текст короткий, поэтому её глоссарий стоит на стр. 1, рядом с текстом.

Типографика подстраивается под длину текста: длинный набирается плотнее, короткий —
крупнее, поэтому текст всегда занимает ровно один лист без пустот и обрезки.

## Грамматика: Past Simple (листы VI–X)

Не привязана к текстам — это самостоятельная отработка Past Simple на тех же трёх
персонах. Охват: утверждения, отрицания и вопросы; `was/were`, правильные и
неправильные глаголы, `didn't`, `did` в вопросах.

- **листы VI–VIII** — по 2 упражнения на каждого: тест с вариантами a/b/c (12 пунктов)
  и раскрыть скобки (10 пунктов)
- **лист IX** — все трое вперемешку: тест (15), составить вопрос из слов (6),
  раскрыть скобки (12), таблица неправильных глаголов (10)

**Все факты сверены** с биографическими источниками перед вёрсткой. Два широко
растиражированных сюжета про Диану подтвердить не удалось — рукопожатие с больным
СПИДом без перчаток и проход по минному полю в Анголе, — поэтому их в заданиях нет,
использованы только общие формулировки. Отец Ньютона не упоминается вовсе: текст
учителя и исторические источники расходятся в том, когда он умер, и задание на этом
факте тихо противоречило бы листу I.

## ⚠️ Найденные ошибки в исходных материалах

Разбор PPTX и сверка с историческими источниками выявили три расхождения.
Подробности — на листе V, стр. 2 («Before you print»).

1. **Wild Card 600 — неверный ответ на слайде.** В игре порядок «Newton → Nelson →
   Elizabeth → Lennon → Diana». По годам рождения верно: **Elizabeth I (1533) →
   Newton (1642) → Nelson (1758) → Lennon (1940) → Diana (1961)**.
   В задании 2 листа IV использован **исправленный** порядок.
2. **Childhood 300 — рассогласование рода.** «Who was raised by *her* strict aunt
   Mimi?» при ответе «John Lennon». Должно быть *his*. В комплекте исправлено.
3. **Текст о Ньютоне расходится с историей** в трёх местах (кто забрал его из школы,
   «пирамида» вместо призмы, поздравление короля). Лист Ньютона намеренно оставлен
   **как есть — строго по тексту и игровому полю**: расхождения разбираются устно.
   Заметка на листе V (только для учителя) годится как шпаргалка для такого разбора.

Тексты воспроизведены дословно, включая американское написание *colors* в тексте о
Ньютоне (в остальном комплекте — британское). Менять — в `build/content.py`.

## Пересборка

```bash
pip install playwright numpy Pillow python-docx
python3 build/verify.py     # 93 проверки содержания
python3 build/make_paper.py # фон-подложка (нужен один раз, файл уже в репозитории)
python3 build/build.py      # HTML + PDF, цветной и ч/б, с контролем переполнения
python3 build/make_docx.py  # редактируемые версии для Word
```

`build/verify.py` ловит то, что пропускает вычитка: разошедшийся word bank,
вопрос Jeopardy, дублирующий задание на той же странице, ключ сопоставления,
по которому ответы читаются прямо с листа, разъехавшийся порядок вариантов между
Word и PDF (иначе один ключ перестал бы подходить к обеим версиям), а в грамматике —
пункт, где правильный вариант всегда под одной и той же буквой, и набор слов, из
которого нельзя собрать заявленный вопрос.
`build/build.py` замеряет каждую страницу и завершается с ошибкой, если
содержимое вылезло за пределы A4.

**Оговорка по DOCX:** Word не воспроизводит фактуру бумаги, гравюрные рамки и
цветные плашки — там та же вёрстка, но оформление проще. Порядок заданий,
формулировки и ключи совпадают с PDF (проверяется автоматически).

Правки контента — в `build/content.py`, оформление — в `materials/html/style.css`.

Фактура бумаги — это один запечённый JPEG (`materials/img/paper.jpg`), а не живые
CSS-градиенты с шумом: последние Chromium не умеет держать вектором и растрировал
каждую страницу отдельно, отчего цветной комплект весил 12 МБ вместо 2,6 МБ.
