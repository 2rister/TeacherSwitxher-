# Рефлексия за 2025/2026 учебный год

Рабочий репозиторий: тезисы («тейки») → развёрнутый текст в жанре рассказа.

## Структура

- `reflection/draft.md` — рабочий черновик рефлексии
- `reflection/takes.md` — исходные тезисы в том виде, как они были надиктованы
- `humanizer/` — правила «оживления» текста (см. `humanizer/ORIGIN.md`)

## Рабочий процесс

1. Тезис записывается в `takes.md` дословно, без правки.
2. Тезис разворачивается в кусок рассказа: сцена, конкретика, вывод.
3. Готовый кусок прогоняется по чек-листу `humanizer/humanizer.ru.md`.
4. Всё коммитится, чтобы черновик не потерялся между сессиями.
