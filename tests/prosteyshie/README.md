# Тест «Простейшие» — печатная версия

Печатная версия теста Wayground (formerly Quizizz) по теме «Простейшие»:
30 вопросов с выбором одного ответа из четырёх, 8 из них — с иллюстрациями.
Материал расшифрован с 16 скриншотов прохождения теста.

## Файлы

| Файл | Что это |
|---|---|
| `test.pdf` | Вариант для учеников, A4, 4 страницы, без ответов |
| `answers.pdf` | Ключ для учителя, 1 страница |
| `test.html` / `answers.html` | То же в HTML — можно печатать из браузера (Ctrl+P) |
| `questions.json` | Исходные данные: тексты, варианты, правильные ответы |
| `images/` | Иллюстрации, вырезанные со скриншотов (вопросы 3, 7, 8, 14, 15, 19, 20, 23) |
| `build.py` | Сборка HTML и PDF из `questions.json` |

## Пересборка

```bash
python3 build.py
```

PDF печатается headless-Chromium'ом. Если его нет в системе, скрипт соберёт
только HTML — его можно распечатать из браузера.

Чтобы поправить формулировку или правильный ответ, редактируйте
`questions.json` и запускайте сборку заново. Поле `answer` — индекс верного
варианта в массиве `options`, нумерация с нуля. Поле `note` (необязательное)
печатается сноской в ключе учителя.

## Правки относительно оригинала

- Правильные ответы на скриншотах не отмечены — проставлены по биологии.
- Убрана статистика прохождения в процентах (58 %, 94 % и т. д.).
- Исправлены опечатки исходного теста: «обыкновеной» → «обыкновенной»,
  «Формаминифера» → «Фораминифера», расставлена «ё».
- Вопросы 4 и 17 в исходнике допускают более одного верного ответа —
  в ключе они помечены звёздочкой и прокомментированы.
